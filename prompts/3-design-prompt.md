# Prompt

```markdown
# ROLE

Bạn là Senior UI Designer và Front-end Developer chuyên thiết kế landing page tối ưu chuyển đổi.

# INPUT

Dựa trên Landing Page Brief đính kèm.

# TASK

Tạo giao diện landing page hoàn chỉnh.

Thiết kế đầy đủ:

1. Layout:

   * Grid, container, spacing và phân cấp thị giác.
   * Responsive trên desktop, tablet và mobile.

2. Color Scheme:

   * Primary, secondary, accent, background, text.
   * Success, warning và error.
   * Khai báo bằng design tokens hoặc CSS variables.

3. Typography:

   * Font family, size, weight, line-height và letter-spacing.
   * Tạo hierarchy rõ ràng cho heading, body, label và caption.

4. Buttons:

   * Primary, secondary và text button.
   * Default, hover, active, focus, loading và disabled.

5. Navigation:

   * Header rõ ràng, CTA nổi bật.
   * Menu mobile dễ sử dụng.
   * Sticky navigation chỉ khi thực sự cần thiết.

6. Icons:

   * Sử dụng một hệ icon thống nhất.
   * Không dùng emoji thay icon giao diện.

7. Forms:

   * Label, input, select, checkbox, radio và validation.
   * Có trạng thái focus, error, success, disabled và loading.
   * Thông báo lỗi cụ thể, dễ hiểu.

8. Imagery:

   * Áp dụng đúng phong cách hình ảnh đã chọn.
   * Nếu thiếu ảnh, dùng placeholder ghi rõ loại ảnh cần cung cấp.

9. Interaction States:

   * Hover, focus, active, loading, success và error.
   * Animation nhẹ, có mục đích và không gây mất tập trung.

# DESIGN RULES

* Đảm bảo responsive cho desktop, tablet và mobile.
* Không tự thêm claim, testimonial hoặc số liệu.
* Ưu tiên khả năng đọc và chuyển đổi hơn trang trí.
* Đảm bảo màu chữ có độ tương phản tốt.
* Vùng bấm trên mobile phải đủ lớn.
* Không lạm dụng animation, gradient, shadow, card hoặc border-radius.
* Không dùng Lorem Ipsum.
* Tham khảo các trang web chuyên nghiệp trên thị trường, sử dụng thiết kế hiện đại, hợp mắt người xem.
* Self-host bộ icon.
* Căn giữa theo chiều dọc cho Hero ở mọi thiết bị
* Chuyển điều khoản dịch vụ và thông báo quyền riêng tư Markdown thành trang HTML
* Phần Hero cần chiếm trọn vẹn một trang trên mọi giao diện trình duyệt (large desktop 1920x1080 and larger, small desktop, tablet, mobile)
* Tạo favicon phù hợp với phong cách của trang

# OUTPUT

Tạo giao diện chạy được bằng HTML, JS, CSS lưu trong thư mục `public`. Tuân thủ quy định về coding convention trong [code_folder.md](../docs/code_folder.md)

Sau khi hoàn thành, cung cấp:

* Danh sách file đã tạo hoặc chỉnh sửa.
* Tóm tắt design system.
* Danh sách tài nguyên còn thiếu.
* Những điểm cần kiểm tra trước khi đưa lên production.
```
